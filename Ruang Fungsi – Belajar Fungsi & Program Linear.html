Fungsi Linear dan Fungsi Kuadrat

Dua fungsi paling dasar: yang satu grafiknya garis lurus, yang lain berbentuk parabola.

Fungsi linear

Bentuk umum dengan m sebagai gradien (kemiringan) dan c sebagai titik potong sumbu-y. Grafiknya selalu garis lurus.

f(x) = mx + c
Gradien dua titik: m = (y₂ − y₁) / (x₂ − x₁)
Titik potong sumbu-x: x = −c / m

Jika m > 0 garis naik, jika m < 0 garis turun.

Fungsi kuadrat

Grafiknya parabola. Jika a > 0 terbuka ke atas, jika a < 0 terbuka ke bawah.

f(x) = ax² + bx + c
Diskriminan: D = b² − 4ac
Akar: x = (−b ± √D) / 2a
Puncak: (−b/2a , −D/4a)

D > 0 dua akar berbeda, D = 0 satu akar, D < 0 tidak ada akar real.

Komposisi dan Invers Fungsi

Komposisi menggabungkan dua fungsi menjadi satu. Invers membalik kerja sebuah fungsi.

Komposisi

Hasil fungsi dalam dimasukkan ke fungsi luar.

(f ∘ g)(x) = f(g(x))
(g ∘ f)(x) = g(f(x))
(f ∘ f)(x) = f(f(x))
(g ∘ g)(x) = g(g(x))

Pada umumnya f ∘ g ≠ g ∘ f.

Invers

f⁻¹ ada jika f berkorespondensi satu-satu. Caranya: tulis y = f(x), ubah menjadi x = …, lalu tukar x dan y.

f(x) = ax + b ⇒ f⁻¹(x) = (x − b) / a
f(f⁻¹(x)) = f⁻¹(f(x)) = x
(f ∘ g)⁻¹ = g⁻¹ ∘ f⁻¹

Program Linear

Mencari nilai maksimum atau minimum sebuah fungsi tujuan di bawah batasan berupa pertidaksamaan linear.

Komponen

Fungsi tujuan z = px + qy yang akan dimaksimumkan atau diminimumkan. Kendala berupa pertidaksamaan linear ax + by ≤ c atau ≥ c, ditambah x ≥ 0 dan y ≥ 0.

z = px + qy

Langkah metode titik pojok

  1. Ubah soal cerita menjadi model matematika.
  2. Gambar garis kendala dan arsir daerah penyelesaian.
  3. Tentukan titik-titik pojok daerah itu.
  4. Hitung z di setiap titik pojok.
  5. Ambil nilai terbesar (maks) atau terkecil (min).
